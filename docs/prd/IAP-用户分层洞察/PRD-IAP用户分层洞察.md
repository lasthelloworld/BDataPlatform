## 三、需求概述

### 3.1 业务痛点

原有 6 份独立报表筛选维度高度重复，前端菜单过多、维护成本高；业务人员需反复切换页面重复筛选，数据对比效率低；纯表格数据可读性差，缺少可视化对比能力。

### 3.2 产品核心目标（Trae 开发验收标准）

1. 合并全部通用筛选维度，一套全局筛选跨 2 大 Tab 复用，减少重复组件；
2. 全部业务指标使用 ECharts 图表可视化，支持多维度横向 / 趋势对比；
3. 单页面承载原 6 份报表全部指标，仅通过 Tab 切换区分两大业务模块，不新增页面菜单；
4. 筛选实时联动所有图表，交互逻辑与原型完全一致；
5. 统一 B 端视觉规范，适配 1200px\~1920px 桌面分辨率。

### 3.3 目标使用人群

投放运营、IAP 会员运营、内容运营、产品数据分析师

## 六、Tab1：用户分层看板（原型左侧 Tab，整合 4 张原始报表）

### 6.1 Tab1 局部筛选栏（全局筛选下方，仅当前 Tab 生效）

组件顺序：用户类型单选 → 会员类型多选 → 内容等级多选

### 6.2 模块 1：会员维度分层（原报表 1）

1. 生效筛选：全局筛选 + Tab1 局部「用户类型」
2. 顶部指标大字卡片：DAU 总活跃设备
3. 图表类型：环形饼图
4. 展示维度：non 非会员、lite、pro、max 四类活跃占比
5. 指标口径：
   - lite 活跃占比 = lite 活跃人数 / DAU
   - pro 活跃占比 = pro 活跃人数 / DAU
   - max 活跃占比 = max 活跃人数 / DAU
6. 原型交互：饼图 hover 展示分层设备数、百分比；图例区分四类会员

### 6.3 模块 2：内容维度分层（原报表 2）

1. 生效筛选：全局筛选 + Tab1 局部「用户类型」
2. 图表类型：双轴柱状图
   - 左 Y 轴：DAU 内 L0/L2/L3 内容触达设备占比
   - 右 Y 轴：触达 L0/L2/L3 内容的设备中会员占比
3. 指标口径：
   - L0/L2/L3 人数占比 = DAU 中至少浏览 1 次对应内容设备 / DAU
   - L0/L2/L3 会员占比 = 浏览对应内容的会员设备 / 浏览该内容总设备

### 6.4 模块 3：注册时间维度分布（原报表 3）

1. 生效筛选：全局筛选 + Tab1 局部「会员类型 + 内容等级」
2. 双图表组合（同一张卡片内上下布局，原型原样）
   - 上方：环形饼图，展示全量 DAU 注册时长整体分布
   - 下方：横向堆叠柱状图，横轴 L0/L2/L3，堆叠展示各注册区间占比
3. 注册分层区间（固定 5 档）：注册 0 天、1-3 天、4-7 天、8-30 天、31 天以上
4. 口径：注册 X 天占比 = 查询日匹配该注册区间设备 / DAU

### 6.5 模块 4：留存维度分布（原报表 4）

1. 生效筛选：全局筛选 + Tab1 局部「会员类型 + 内容等级」
2. 图表类型：多线面积趋势图
3. 曲线：次留、7 留、14 留、30 留四条曲线同期对比
4. 口径：留存率 = 对应留存设备数 / 当日 DAU
