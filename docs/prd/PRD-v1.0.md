# 销售数据分析看板 PRD

## 1. 文档版本信息

- 需求名称：销售数据分析看板
- 版本：v1.0
- 创建日期：2026-05-03

## 2. 业务背景与目标

### 2.1 背景

当前销售团队缺乏统一的数据可视化平台，各区域销售数据分散在多个系统中，管理层无法实时掌握整体销售态势，区域负责人难以快速定位业务问题。为提升数据驱动决策效率，需构建标准化、可配置的销售数据分析看板，实现核心指标的实时监控与下钻分析。

### 2.2 目标

1. 实现销售核心指标（销售额、订单量、客单价、同比增长率）的实时可视化展示
2. 支持按区域、时间维度灵活筛选，满足不同层级用户的分析需求
3. 提供趋势分析、结构分析及明细查询能力，支撑业务问题定位
4. 支持数据导出，便于线下汇报与二次分析
5. 确保数据口径统一，降低跨部门沟通成本

### 2.3 用户角色

| 角色    | 核心需求            | 使用场景                |
| :---- | :-------------- | :------------------ |
| 销售总监  | 全局销售态势监控、区域业绩对比 | 每日晨会查看整体达成情况，识别落后区域 |
| 区域经理  | 本区域销售明细、趋势追踪    | 周度复盘分析区域业绩波动原因      |
| 数据分析师 | 数据导出、多维下钻       | 月度经营分析报告数据准备        |
| 运营支持  | 订单明细查询、异常数据反馈   | 处理客户咨询时快速定位订单信息     |

## 3. 功能需求（包含 P0/P1/P2 优先级）

### 3.1 核心指标看板模块（P0）

- 功能描述：展示总销售额、订单量、客单价、同比增长率4大核心指标卡片，支持时间范围与区域筛选联动
- 前置条件：用户已登录且拥有销售数据查看权限；数据仓库已完成T+1数据同步
- 操作步骤：
  1. 进入看板页面，默认展示近30天全国数据
  2. 通过顶部筛选器选择时间范围（支持自定义起止日期）及区域（省/市多级联动）
  3. 系统自动刷新指标卡片及关联图表
- 预期结果：
  - 4项指标实时渲染，金额单位显示为"万元"，同比增长率保留1位小数并带↑↓标识
  - 筛选条件变更后，所有组件在1.5秒内完成数据更新
- 数据规则：
  | 字段    | 来源       | 更新频率      | 计算逻辑                           |
  | :---- | :------- | :-------- | :----------------------------- |
  | 总销售额  | ODS订单事实表 | T+1 02:00 | SUM(订单实付金额)，单位：万元              |
  | 订单量   | ODS订单事实表 | T+1 02:00 | COUNT(DISTINCT 订单ID)           |
  | 客单价   | 计算字段     | 实时计算      | 总销售额/订单量，单位：万元，保留2位小数展示        |
  | 同比增长率 | 计算字段     | 实时计算      | (本期值-去年同期值)/去年同期值\*100%，保留1位小数 |

### 3.2 可视化图表模块（P0）

- 功能描述：提供月度销售趋势折线图、区域销售占比饼图，支持图表联动与下钻
- 前置条件：核心指标模块已加载完成
- 操作步骤：
  1. 查看折线图：横轴为月份（YYYY-MM格式），纵轴为销售额（万元），悬停显示具体数值
  2. 查看饼图：点击某区域扇区，下钻至该区域下属城市分布
  3. 联动操作：点击折线图某月份，饼图自动切换至该月区域分布
- 预期结果：
  - 折线图平滑渲染，支持缩放查看细节；饼图标签清晰，占比数值保留1位小数
  - 下钻路径面包屑导航，支持返回上一级
- 数据规则：
  | 字段    | 来源       | 更新频率 | 说明                           |
  | :---- | :------- | :--- | :--------------------------- |
  | 月度销售额 | DWD销售聚合表 | T+1  | 按自然月聚合，单位：万元                 |
  | 区域占比  | DWD销售聚合表 | T+1  | 按省级行政区聚合，占比=区域销售额/总销售额\*100% |

### 3.3 订单明细表格模块（P1）

- 功能描述：展示筛选条件下的订单明细列表，支持分页、排序、关键字搜索
- 前置条件：已选择筛选条件（时间+区域）
- 操作步骤：
  1. 表格默认按订单时间倒序排列，每页展示20条
  2. 点击表头可按销售额、订单时间等字段排序
  3. 输入订单号/客户名关键字，实时过滤表格数据
- 预期结果：
  - 表格加载时间≤1.5秒，金额列统一显示为"万元"格式
  - 搜索响应时间≤500ms，无结果时显示友好提示
- 数据规则：
  | 字段   | 来源       | 更新频率 | 格式要求                |
  | :--- | :------- | :--- | :------------------ |
  | 订单号  | ODS订单主表  | T+1  | 字符串                 |
  | 下单时间 | ODS订单主表  | T+1  | YYYY-MM-DD HH:mm:ss |
  | 客户名称 | DIM客户维度表 | T+1  | 字符串                 |
  | 订单金额 | ODS订单事实表 | T+1  | 数值，单位：万元，保留2位小数     |
  | 所属区域 | DIM区域维度表 | T+1  | 省-市二级联动显示           |

### 3.4 数据导出功能（P1）

- 功能描述：支持将当前筛选条件下的指标数据、图表数据、明细表格导出为Excel
- 前置条件：用户拥有"数据导出"权限
- 操作步骤：
  1. 点击页面右上角"导出"按钮
  2. 选择导出内容（指标摘要/图表数据/明细表格/全选）
  3. 确认导出，系统生成文件并自动下载
- 预期结果：
  - 导出文件命名规则：销售数据分析\_区域\_时间范围\_导出时间.xlsx
  - 金额列自动设置为数值格式，百分比列保留1位小数
  - 10万行以内数据导出耗时≤30秒
- 数据规则：导出数据与页面展示完全一致，遵循相同口径与格式规范

### 3.5 权限管理与数据隔离（P2）

- 功能描述：基于角色实现数据行级隔离，确保用户仅查看授权区域数据
- 前置条件：用户角色已在权限系统完成配置
- 操作步骤：
  1. 用户登录后，系统自动识别角色及数据权限
  2. 区域筛选器仅展示该用户有权查看的区域选项
  3. 无权限区域数据在图表/表格中自动过滤
- 预期结果：
  - 区域经理仅能看到本区域及下属城市数据
  - 销售总监可查看全国数据，但敏感字段（如客户手机号）自动脱敏
- 数据规则：权限规则同步自统一权限中心，变更实时生效

## 4. 非功能需求

- 性能：
  - 首屏加载时间 ≤ 1.5 秒（3G网络环境下）
  - 筛选条件变更后，所有组件数据刷新 ≤ 1.5 秒
  - 支持并发用户数 ≥ 200，响应时间波动 ≤ 20%
- 权限：
  - 基于RBAC模型实现角色-权限-数据三级隔离
  - 敏感操作（导出、下钻）记录操作日志，保留180天
- 兼容性：
  - 支持Chrome 90+、Edge 90+、Safari 14+ 浏览器
  - 适配1920*1080及1366*768主流分辨率
- 可维护性：
  - 指标计算逻辑配置化，支持后台动态调整
  - 提供数据质量监控告警，异常时自动通知管理员

## 5. 验收标准

- 核心指标展示\_选择时间范围2026-01-01至2026-03-31\_总销售额显示为XXX.X万元，同比增长率保留1位小数并带方向标识
- 区域筛选\_选择"华东大区"\_饼图仅展示华东下属省份数据，占比之和=100.0%
- 图表联动\_点击折线图2026-02月\_饼图自动切换至2月区域分布，明细表格同步刷新
- 明细查询\_输入订单号"ORD20260001"\_表格精准定位该订单，金额显示为X.XX万元
- 数据导出\_选择"明细表格"导出\_生成Excel文件，金额列格式为数值型，百分比列保留1位小数
- 权限控制\_区域经理账号登录\_筛选器仅显示本区域选项，尝试访问其他区域数据返回空结果
- 性能测试\_200并发用户筛选操作\_95%请求响应时间 ≤ 1.5秒，无超时失败

***

> 备注：本PRD严格遵循B端数据产品设计规范，所有金额单位统一为"万元"，百分比字段保留1位小数，日期格式采用YYYY-MM-DD标准。开发前需与数据团队确认指标口径，与权限团队对齐数据隔离规则。
