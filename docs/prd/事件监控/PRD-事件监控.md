事件监控预警平台 · 高保真原型设计说明
本文档用于指导原型工具（如Trae、Figma、Axure）生成高保真交互原型，描述页面布局、功能模块、交互细节及数据逻辑。所有内容基于已确认的规则引擎元模型和业务场景建模。

一、整体信息架构
1.1 导航结构
左侧边栏（固定宽度 240px）：

Logo：品牌名 "WatchDog" + 闪电图标

主导航菜单：监控概览、规则管理、告警历史、字段管理（系统设置）

项目组切换区：展示当前用户有权限的项目组列表，每个项目组带状态指示灯（绿/黄/灰）

底部系统状态：运行状态 + 版本号

顶部栏（全局固定在主内容区顶部）：

左侧：当前页面标题 + 面包屑

右侧：全局搜索框（搜索规则名称/项目组）、新建规则按钮（主操作）

1.2 页面清单
页面	路由	核心功能
监控概览	/dashboard	展示关键指标、异常趋势、最新告警，全局入口
规则管理	/rules	查看所有规则列表（支持筛选/搜索/启用停用/编辑/删除）
新建/编辑规则	模态框或独立页面	完整配置规则（过滤器、计算因子、窗口、阈值、动作）
告警历史	/alerts	查看历史告警记录，支持明细导出、状态标记
字段管理	/fields	管理标准字段与自定义字段的映射、索引分级（S/A/B）
二、页面详细设计
2.1 监控概览（Dashboard）
布局结构
统计卡片区域（一行四列）：

卡片1：监控规则总数 → 数值 + 本周新增变化（箭头 + 百分比）

卡片2：今日告警数 → 数值 + 未处理数（红色标记）

卡片3：事件吞吐量（过去1小时总量） → 数值 + 单位（万/百万）

卡片4：异常率（过去1小时异常事件占比） → 数值 + 较昨日变化（箭头 + 百分比）

图表与告警列表区域（两行或左二右一布局）：

左侧（占2/3宽度）：异常事件趋势图

折线图展示近1小时内每5分钟聚合的异常事件数量

叠加一条水平阈值参考线（可配置，默认显示全局平均阈值）

鼠标悬停显示具体数值

右侧（占1/3宽度）：最新告警列表

展示最近5条告警记录，每条显示：告警规则名称、触发时间、项目组、严重程度（颜色标识）

底部“查看全部”链接跳转至告警历史页

交互细节
统计卡片悬停时轻微上浮（阴影加深），点击可跳转至对应详情（如点击“今日告警”跳转到告警历史并自动过滤今日）

趋势图支持点击图例切换数据系列显示/隐藏

告警列表滚动加载更多（若超过5条）

2.2 规则管理（Rules List）
页面功能
工具栏：

左侧：项目组下拉筛选（默认全部）、启用状态筛选（全部/已启用/已停用）

右侧：搜索框（按规则名称）、新建规则按钮（与顶部一致）

规则列表表格（列）：

规则名称（带是否启用开关）
项目组
计算因子简述（如“AVG(params.ecpm)”）
触发条件简述（如“< 0.5”）
时间窗口
执行频率（实时/5分钟/每小时/T+1）
最近触发时间
操作（编辑 | 复制 | 停用/启用 | 删除）
交互细节
启用开关为滑动按钮（toggle），点击后立即生效，并伴随轻微动画

行悬停时显示操作按钮（默认隐藏）

点击行任意处可展开详情面板（显示完整配置、最近告警记录、命中样本数）

删除操作需二次确认弹窗

“复制”规则：弹出快速复制窗口，默认填充原配置，允许修改名称和部分参数后保存为新规则

2.3 新建/编辑规则（核心配置模态框）
触发方式
点击“新建规则”按钮（全局）或规则列表中的“编辑”/“复制”

模态框布局（宽度≥900px，高度自适应，内容可滚动）
分区顺序（从上到下）：

基本信息区（两栏布局）

规则名称（文本输入框，必填）

所属项目组（下拉选择，必填，选项来自权限范围）

规则描述（可选，文本域，折叠显示）

执行计划区（两栏布局，带浅色背景区分）

执行频率：下拉选项（实时、每5分钟、每小时、每日T+1）

时间窗口：下拉选项（动态绑定，根据频率推荐；如“实时”只允许“逐条”；“每5分钟”推荐“最近5/10/15分钟”等）

当选择“每日T+1”时，额外显示“计算时间：每日凌晨01:00”

条件过滤器（WHERE）（核心复杂组件）

标题区：显示“条件过滤器 (WHERE)” + “添加条件”按钮 + “添加条件组”按钮（两个按钮并列）

主体：一个或多个条件组（根组默认存在）

每个条件组是一个矩形区块，左侧有竖条颜色标识（蓝色表示AND组，橙色表示OR组）

组标题显示逻辑运算符（AND / OR），可通过下拉切换

组内包含若干条件行（每行一条）

条件行包含：字段选择器（下拉，分组显示标准字段/自定义S级/派生字段）、操作符选择器（下拉）、值输入器（根据操作符动态变化）、删除按钮（×）

字段选择器分组示例：

标准字段：event_id, user_pseudo_id, country, event_time 等

自定义字段（S级）：params.type1, params.ecpm, params.unit_id 等

派生字段：delay（由 event_time - client_time 生成）

操作符根据字段类型动态过滤（数值字段支持 >/<，字符串支持 LIKE/IN 等）

值输入器：文本输入框/数字输入框/枚举标签输入（IN时）/日期时间选择器（时间戳字段）

每个条件行右侧有“删除条件”按钮

组底部有“添加条件”按钮（在组内增加一行）和“删除组”按钮

条件组可以嵌套：点击“添加条件组”会在当前组内创建一个子组（缩进显示）

计算因子（Metric）区（网格三列布局）

计算类型：下拉（聚合值、单条值、空值率、占比、顺序匹配、转化率）

聚合函数（仅当计算类型为“聚合值”时显示）：下拉（COUNT, SUM, AVG, MAX, MIN, COUNT_DISTINCT, P99）

目标字段：下拉（只显示数值型字段，如 params.ecpm，event_time 等）

若选择“空值率”，额外显示“指定字段”下拉（选择要检查空值的字段）

若选择“占比”，动态显示两个条件编辑器（分子过滤条件组、分母过滤条件组），支持与主过滤器相同的嵌套逻辑

若选择“顺序匹配”，显示“事件序列”输入（有序事件ID列表，用逗号分隔）和“最大允许间隔（分钟）”数字输入框

若选择“转化率”，显示“步骤事件列表”（多行输入，每行一个事件ID）和“目标转化率”阈值输入

阈值触发区（两栏布局，浅红色背景提示）

比较操作符：下拉（>, <, >=, <=, =, !=）

阈值：输入框（数值/百分比，根据计算类型自动调整单位提示，如“%”或“毫秒”）

实时预览文本：显示当前配置的完整判断逻辑，如“当 AVG(params.ecpm) < 0.5 时触发告警”

告警动作区

通知渠道：复选框组（钉钉、企业微信、邮件、飞书、自定义Webhook）

接收人：文本输入框（支持邮箱、手机号、钉钉ID等，用逗号分隔）

告警收敛：

静默期（分钟）：数字输入框（默认30）

防抖开关：启用后，连续触发时合并通知

恢复通知开关：异常恢复后发送“已恢复”通知

底部操作按钮

“取消”（关闭模态框）

“保存规则”（提交配置，根据频率立即或延迟生效）

交互细节
字段选择器变更时，自动更新操作符可选项和值输入器类型

条件组嵌套时，通过缩进和不同色条区分层级（最大支持5层）

添加条件/组时，动画插入新行/组

实时预览阈值描述随配置变化动态更新

选择“每日T+1”频率时，窗口自动锁定为“昨日全天”且不可更改，并提示计算时间

若有必填项未填，保存按钮置灰并提示错误

2.4 告警历史（Alert History）
页面功能
筛选区：项目组下拉、时间范围选择器（默认最近7天）、规则名称搜索、告警状态（全部/未处理/已忽略/已恢复）

统计信息：顶部显示“总告警数”、“未处理数”、“已恢复数”

告警列表（表格）：

列：触发时间、规则名称、项目组、计算值/阈值、状态（标签：未处理/已忽略/已恢复）、操作（查看详情 | 标记处理 | 忽略）

详情抽屉：点击“查看详情”从右侧滑出，展示：

规则完整配置快照

触发时的窗口范围

命中数据样本（最多10条，展示关键字段）

“导出明细”按钮（导出命中数据完整日志，格式CSV）

交互细节
状态标签颜色：红色（未处理）、灰色（已忽略）、绿色（已恢复）

支持批量标记处理（勾选多条后操作）

导出明细时，后台异步生成下载链接（通知用户）

2.5 字段管理（Field Management）
页面功能
介绍：管理项目中所有可用的字段元数据，控制字段在规则配置中的可见性和索引级别

字段列表（表格）：

列：字段路径（如 params.ecpm）、字段名称（可编辑）、数据类型（自动识别/手动设置）、索引级别（S/A/B，下拉可切换）、所属项目组（多选）、最后更新时间

操作：

“添加自定义字段”按钮：弹出表单，输入字段路径、名称、数据类型、索引级别

“从样本探查”功能：输入一个项目组和日期，系统自动发现近15天 params 中出现过的所有Key，推荐添加到字段管理

索引级别说明（悬停显示）：

S级：支持聚合（SUM/AVG）、分组，存入列式存储

A级：仅支持过滤（WHERE），不支持聚合

B级：仅用于明细展示，不参与计算

交互细节
修改索引级别后，系统检查已有规则是否依赖该字段的聚合功能，若有冲突给出警告提示

“从样本探查”异步进行，完成后列出新字段供用户勾选加入管理

三、通用组件与交互规范
3.1 全局组件
加载状态：骨架屏或旋转Spinner

空状态：无数据时显示占位图+引导文案（如“还没有规则，点击新建”）

错误提示：Toast消息（右上角），红色背景，3秒自动消失

确认对话框：删除等危险操作弹出，需输入操作确认或点击“确认删除”

3.2 交互反馈
所有按钮点击有按压态（颜色加深）

保存成功/失败后Toast提示

表格行支持排序（点击列头）

模态框打开时背景模糊

3.3 响应式
原型优先考虑桌面端（分辨率≥1280px），但不影响移动端适配预览

四、数据模拟与状态示例
为了原型展示，可预设以下模拟数据：

项目组：广告聚合、用户增长、内容中台

规则示例：

“Ecpm低值监控”：AVG(params.ecpm) < 0.5，每5分钟，实时通知
“空值率监控”：NULL_RATE(account_id) > 5%，T+1，邮件通知
“事件顺序异常”：SEQUENCE_MATCH('40601','40602','40605')，实时，钉钉通知
告警历史：最近1小时产生8条告警，其中4条未处理
