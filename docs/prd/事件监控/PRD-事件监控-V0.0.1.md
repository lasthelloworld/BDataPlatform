# 监控中心V0.0.1 需求文档

## 1. 需求背景

​	事件监控中心用于监控管理各类事件，助力用户及时发现并处理问题，提升系统稳定性与可靠性。当前业务中，PM、SDK 研发及运营人员需人工监测广告事件上报、投放归因及用户行为事件是否正常，存在监控不及时、排查效率低的问题；且依赖 BI 研发人员手动导数核对，定位条件不统一，占用大量研发时间用于事件日志排查，亟需优化。

## 2. 功能目标

​	支持PM，运营，SDK登录后台系统配置自己产品组具体BI公共维度范围的自定义监控规则，支持监控日志查询，对及时性高的监控预警进行通知，需包含企业微信和短信通知。

## 3. 功能范围

**1.监控规则配置：**
按运营，PM，SDK研发人员三类，支持用户根据BI公共维度，在指定产品或版本范围内，配置自定义监控规则，支持规则启停，删除。
**2.监控日志查询：**

​	支持用户根据监控规则，查询所有日志，并查看日志详情，日志详情可查看命中的数据明细信息。
**3.监控通知：**

​	对于及时性高的监控，需支持小时/天级监控，本期仅支持两种方式通知：企业微信，短信。

## 4. 详细需求

**4.1 业务流程**

1\. 用户登录后台系统，进入监控规则配置页面，配置自定义监控规则。

2\. 系统T+1或H+1生成监控日志数据，并根据规则配置的通知规则，进行监控通知。

3\. 用户登录后台系统，进入监控日志查询页面，查询所有日志，并查看日志详情。

**4.2 功能模块**

**1.监控规则配置：**

支持后台监控自定义规则配置，用户可以根据不同BI公共维度，配置自定义的监控规则；

一条自定义规则需包含：

​        首先是用户可以基础信息：规则名称，规则描述（文本域框）；

**（1）监控维度**
本期仅包含：产品组->app->app\_version->国家->投放渠道选择，用于框定事件日志监控范围。

| 项            | 控件类型 | 值        | 备注                                |
| ------------ | ---- | -------- | --------------------------------- |
| 产品组          | 下拉框  | 组织架构产品组  | 多选必选，如：产品1组，产品2组                  |
| app          | 下拉框  | 产品组下级app | 多选非必选，如：Photo Recover,PhotoRescue |
| app\_version | 下拉框  | app对应版本号 | 多选非必选，如v1.0.0                     |
| 国家           | 下拉框  | 事件触发国家   | 多选非必选，如美国-us                      |
| 投放渠道         | 下拉框  | 投放渠道     | 多选非必选，FB,Tiktok,google            |

**（2）监控规则条件配置**

一条规则条件项有以下规则元素组成，用户可以自定义添加规则条件元素：

​	字段选择器：主要三类，事件选择器，事件自定义参数选择器，指标字段选择器

​        操作符选择器：（【计算操作符】，【比较操作符】，【逻辑操作符】，【常用聚合操作符】），监控值阈值设置；

一条规则项配置支持：

- ​        基础配置支持用户按监控字段选择器+操作符选择器+监控值域阈值选择器，自由组合生成一个条规则；
- ​        支持1个或者监控字段选择器选择，用户可以使用操作符进行串联；
- ​         规则条件项之间可以使用【逻辑操作符】进行关联。

| 规则元素       | 控件类型 | 值                                                                             | 备注                                        |
| ---------- | ---- | ----------------------------------------------------------------------------- | ----------------------------------------- |
| 事件选择器      | 下拉框  | “event\_id”，“user\_pseudo\_id”，“params”，“其他事件日志字段（见表结构）”                      | 非必填，按需添加，添加后必填，当选择params时，级联展示监控自定义字段选择器  |
| 监控自定义字段选择器 | 下拉框  | 事件Event\_Id对应的param下属json的字段值，如param.type1                                    | 非必填，按需添加，添加后必填；需先选事件选择器，级联选择事件下属自定义字段     |
| 指标选择器      | 下拉框  | 本期仅包含：Cost，CDNU,DNU,DAU                                                       | 非必填，按需添加，添加后必填，这类是非监控日志指标，投放三方指标目前不支持消耗点位 |
| 计算操作符      | 下拉框  | +，-，\*，/                                                                      | 非必填，按需添加，添加后必填                            |
| 比较操作符      | 下拉框  | 大于，大于等于，小于，小于等于，等于，不等于，in，Not In,between,in Range(最近多长时间)，is null,is no null  | 非必填，按需添加，添加后必填                            |
| 逻辑操作符      | 下拉框  | AND（与）,OR（或）,NOT（非）                                                           | 非必填，按需添加，添加后必填,NOT:不符合该条件的数据命中            |
| 聚合操作符      | 控件组  | 计算函数选择器：AVG,SUM,Count,Max,Min；                              目标值选择器：选择参与计算加工的值 | 非必填，按需添加，添加后必填                            |

**（3）监控数据范围时间窗口** **（非必选）**

​	 用于用户选择哪个数据时间范围的数据，两种方式：

​         支撑用户日期选择日期间隔：

| 日期范围 | 说明              |
| ---- | --------------- |
| 近7日  | 每天监控当日至7天内的数据   |
| 近X天  | 每天监控当日至X个天前内的数据 |

​         支持用户选择日期区间范围:选择开始日期和结束日期监控。

**（4）监控频率**（必填）

​	仅支持每日（T+1）,每小时（H+1）.

**（5）监控告警（非必填）**

​	因为有监控日志，不一定非要告警，其中监控触发通知形式（复选框方式）：支持企业微信，短信。

（这里建议企业微信的配置配置几个常用群组，让用户选）

**2.告警历史：**

菜单名称叫：“告警历史”，即监控日志表，支持后台监控日志查询，用户可查询所有日志，并查看日志详情。

顶部展示当日：总告警数（红色），未处理数（橙色），已处理数（绿色）

| 项    | 说明                  | 备注                |
| ---- | ------------------- | ----------------- |
| 总告警数 | 当日满足告警规则的预警数        | 每半小时系统自动刷新一次告警表记录 |
| 未处理数 | 当日满足告警规则的用户未标记预警数   | 每半小时系统自动刷新一次告警表记录 |
| 已处理数 | 当日满足告警规则的用户点击标记已预警数 | 每半小时系统自动刷新一次告警表记录 |

监控日志列表，列与说明如下：

| 列      | 说明                                 | 备注                  |
| ------ | ---------------------------------- | ------------------- |
| 触发执行时间 | 规则触发执行时间，注：不是表示规则命中数据产生时间          | 日时分秒                |
| 规则名称   | 创建规则时用户填写的规则名称                     | <br />              |
| 监控维度   | 所属那个BI公共维度范围的                      | <br />              |
| 规则说明   | 显示一个查看按钮，点击可以弹出此规则明细界面，查看之前用户编写的规则 | <br />              |
| 状态     | 仅两个状态：未处理，已处理                      | <br />              |
| 操作列    | 【标记处理】【查看详情】                       | 点击查看详情可以侧滑查看规则命中的数据 |
| <br /> | <br />                             | <br />              |

**3.告警日志明细：**

​	点击具体行的监控日志【查看详情】，侧滑展示规则命中的明细数据，可以导出。

此界面需包含：

命中规则及规则快照信息（参考规则配置部分），触发窗前期范围和数据条数，命中数据明细。

是一个表格，命中event日志表记录。

**4.监控告警：**

日志输出，对于重要点位进行企业微信和短信通知，支持用户选择通知人。（这期暂不处理）

**5.监控启停与删除：**

规则可以启停，只能逻辑删除，不能物理删除。
