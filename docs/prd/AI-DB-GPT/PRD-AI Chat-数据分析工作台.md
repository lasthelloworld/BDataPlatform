# **PRD-AI-Chat 数据分析功能原型**

基于现有 Vue3 + Ant Design Vue B端数据分析后台项目（已有 `/dashboard` 销售看板页面），**纯增量开发**，新增独立【AI‑Chat】完整功能页面。 硬性约束：仅新增页面相关内容，不输出、不覆盖、不修改原有路由、菜单、布局源码；无弹窗、无悬浮入口；所有交互元素添加 data‑marker 埋点；页面底部配置折叠面板汇总全部埋点；UI 对齐项目 `AGENTS.md` 规范；适配1920分辨率B端后台风格。

## **1. 业务背景与目标**

### **1.1 业务目标**

支持业务人员通过自然语言提问，AI自动解析销售数据需求，完成数据查询、指标计算，输出文本、表格、ECharts图表类分析结果。页面内置7条标准业务示例问题，搭配会话历史管理能力，降低B端用户数据分析门槛。 页面入口：仅左侧导航菜单跳转独立功能页面，**无任何弹窗、悬浮窗口入口**。

### **1.2 用户角色**

面向B端业务分析师、运营、管理人员，满足销售数据统计、指标对比、销售预测、RFM客户分析、省市市场四象限分组分析等业务场景。

### **1.3 页面基础信息**

页面访问路径：`/AI‑Chat` 页面组件路径：`src/views/AI‑Chat.vue`

### **1.4 页面整体布局**

采用**1:3左右分栏固定布局**，左侧会话侧边栏、右侧对话主区域，1:1复刻参考截图的排版、文案、元素位置、样式结构。

## **2. 页面模块、UI与完整交互细节**

### **模块一：左侧会话侧边栏**

埋点标识：`ai‑chat‑sidebar` 元素自上而下完整还原截图：

1. 侧边栏头部：图标+「标准问数演示」标题，右侧带展开箭头，埋点：`sidebar‑collapse‑header`
2. 新增对话按钮：浅色样式「+ 新对话」按钮，埋点：`btn‑new‑chat` 交互：点击清空当前所有会话消息，重置页面为初始欢迎状态，新建空白会话。
3. 折叠菜单：「常看问题」下拉折叠项，埋点：`menu‑common‑questions` 交互：点击展开/收起问题列表。
4. 历史记录区域：包含「历史记录」分组标题、「今天」时间分组、默认「新会话」会话条目，整体埋点：`history‑group`；单条会话埋点：`history‑item‑{id}` 交互：点击条目切换历史会话，加载对应问答记录；hover 展示删除按钮，点击删除弹出确认弹窗，确认后删除当前会话。
5. 侧边栏底部：展示当前登录用户账号信息，埋点：`sidebar‑user‑info`

页面初始化默认自动生成一条名称为「新会话」的空白会话。

### **模块二：右侧对话主区域**

埋点标识：`ai‑chat‑main`

1. 页面右上角固定页面标题：「标准问数演示」，埋点：`main‑page‑title`
2. 欢迎卡片，埋点：`welcome‑card` ‑ 头部：绿色圆形图标 + 标题「嗨～我是 Hopmobi Mind 数据分析助手！」 ‑ 引导文案： ‑ 内置7条**一字不差**的标准业务示例问题：

   “请描述您的数据分析需求或待排查问题，我将自动规划任务并调用工具为您处理。 输入 @ 可唤起 Skills 能力，辅助完成专项任务。 如需了解全部能力，可发送：**支持什么技能**。

   👉 问题定位格式：时间 + 包名 + 分析维度 + 数据异常现象，我将快速帮您定位根因。&#x20;

   👉 数据查询格式：时间 + 包名 + 分析维度 + 查询字段 + 数据展现形式，直接获取明细结果。

   AI 能力持续进化中，您的每一次使用，都将帮助 Hopmobi Mind Agent 持续扩充知识储备，不断强化问题解决能力；”
3. 对话框发送按钮旁边添加一个按钮，按钮图标见上传图片，用户点击可以一键美化输入提示词美化功能；\
   可以对用户输入的提示词语句进行美化，按“时间 + 包名 + 分析维度 + 查询字段 + 数据展现形式/数据异常现象”进行提示词美化；
4. 对话框支持文件上传，两种格式，图片和excel文件上传。需支持Png,jpg,csv,xls格式；
5. AI系统分析输出结果，包含两部分：

   （1）系统分析过程，体现系统分析内部过程，如代码链接，查询连表过程；用户点击展开按钮，右侧侧滑显示分析过程；

   （2）第二部分是，返回给用户的最终结果。在对话框中显示；

交互规则：每条示例问题为独立可点击区域，埋点：`sample‑question‑{num}`（num=1‑7）；**点击仅填充文本至底部输入框，禁止自动发送请求，需用户手动点击发送**。

<br />

状态规则：页面初始加载展示欢迎卡片；用户发送首条消息、切换历史会话后，欢迎卡片自动隐藏，展示问答消息流。

1. 消息流列表容器，埋点：`message‑list` ‑ 用户消息：页面右侧对齐展示提问文本 ‑ AI回复消息：页面左侧对齐，支持渲染普通文本、Markdown表格、ECharts图表 ‑ 加载状态：AI应答过程中展示loading占位状态 ‑ 异常状态：接口请求失败时展示标准错误提示文本 ‑ 初始状态：空白无消息，仅展示欢迎卡片
2. 底部输入操作区，埋点：`chat‑input‑area` ‑ 多行输入框：占位文案「输入你的问题，或使用 "/" 选择常用语」，埋点：`chat‑input` ‑ 发送按钮：输入框右下角向上箭头图标按钮，埋点：`btn‑send` 交互：输入为空时按钮置灰禁用；有内容时可点击，支持鼠标点击、回车键双重发送。 ‑ 底部隐私提示小字：「您正在使用AI工具，请注意保护个人隐私及敏感数据，并审慎核实AI生成的内容。」，埋点：`footer‑tip`
3. 页面最底部增设折叠面板，标题「元素data‑marker清单」，展开后汇总展示页面所有埋点名称，用于测试走查。

## **3. 菜单与路由增量规则（仅行为描述，无代码）**

1. 路由：在项目现有路由体系中**仅增量追加**当前页面路由，不修改、不覆盖原有任何路由配置。
2. 左侧菜单：增量校验新增，优先判断菜单列表是否已存在「AI‑Chat」菜单项，存在则跳过，不存在则新增；菜单名称AI‑Chat、跳转`/AI‑Chat`、robot图标，菜单项埋点：`menu‑item‑ai‑chat`。

## **4. 核心交互逻辑**

1. 新建对话：清空全部消息记录，页面重置为初始欢迎状态。
2. 历史会话切换：点击会话条目，加载对应历史问答，隐藏欢迎卡片。
3. 示例问题交互：仅填充文本，不自动提交。
4. 消息发送交互：提交问题后展示用户消息+AI加载状态，成功渲染结果、失败展示错误提示。
5. 会话持久化：所有会话、问答记录持久化存储，支持历史回溯。

1. 技术栈：Vue3 script setup、Ant Design Vue、ECharts，严格匹配项目现有技术体系。

5. 功能限制：无弹窗、无悬浮聊天入口，仅保留独立页面模式。
