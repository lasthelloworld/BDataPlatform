## 1. 文档版本信息

- 需求名称：本地广告性能报表（Local Ad Performance Report）
- 版本：v1.0
- 创建日期：2026-05-04

## 2. 业务背景与目标

### 2.1 背景

原有 Local Event Report 查询广告性能指标存在以下痛点：

- **操作链路长**：需多次跳转+手动拼接维度，
- **维度隔离**：投放维度（Campaign/AdGroup）与变现维度（广告平台/广告类型）无法关联查询，难以定位"某广告组投放引流APP用户在某广告位的表现"
- **复用成本高**：项目组每次发版/老板周期汇报需重复配置相同筛选条件，无模板化能力

需提炼高频使用的广告性能指标（40xxx 系列事件点位），使用本地事件打点上报进行数据统计，构建标准化报表，支撑发版验收、周期复盘、投变维度查询三大核心场景。

### 2.2 目标

1. **指标聚合**：整合 DAU/DNU、展示/点击/填充率、ECPM/DARPU 等 20+ 核心指标，支持一键查看
2. **维度自由组合**：支持从「项目结构」「投放维」「变现维」「数据期」4 大类 16 个维度项中自由勾选，按勾选顺序动态生成表格固定列
3. **筛选增强**：在 OV 报表基础筛选（时间+区域）上，新增「广告类型」「广告聚合平台」「广告平台」三级变现筛选
4. **效率提升**：查询响应 ≤1.5 秒，支持 Excel 导出，满足老板汇报/项目组复盘的即时出数需求

### 2.3 用户角色

| 角色     | 核心需求             | 使用场景                                 |
| :----- | :--------------- | :----------------------------------- |
| 产品组 PM | 发版后广告性能验收、异常指标归因 | APP 新版本上线后 24h 内，对比旧版填充率/展示率波动       |
| 运营组长   | 广告位收益监控、策略调优     | 每周复盘各 Placement 的 ECPM 表现，调整底价策略     |
| 投放组长   | 投放渠道效果评估、预算分配    | 对比 Google/FB 各 Campaign 的 DARPU，优化出价 |
| 老板/管理层 | 周期业务汇总、关键指标速览    | 月度经营会议，快速查看 Revenue/DARPU 趋势及区域贡献    |

## 3. 功能需求

### 3.1 模块一：Local Ad Performance 报表（P1）

#### 功能描述

- **模块名称**：Local Ad Performance
- **菜单路径**：Team Report → Local Ad Performance
- **核心能力**：
  - 支持时间范围 + 16 个维度项自由组合筛选
  - 勾选的维度项按顺序固化为表格左侧固定列，其余指标列横向滚动
  - 20+ 广告性能指标实时计算，支持导出 Excel

#### 前置条件

- 用户已登录且拥有 `team_report:view` 权限
- 数据仓库已完成 T+1 数据同步（事件点位：40101/40201/40300/40301/40401）

#### 操作步骤

1. 进入报表页面，默认加载「昨日（T+1）」+「全维度汇总」数据
2. 在顶部筛选区：
   - 选择日期范围（支持快捷：近 7 天/近 30 天/自定义）
   - 勾选需分析的维度项（如：APP → Country → 广告类型 → Placement）
   - 可选：指定广告平台（TopOn/Max/AdMob）、广告类型（开屏/插屏）
3. 点击「查询」或筛选条件变更时自动刷新
4. 表格支持：列排序、关键字搜索（订单号/客户名）、分页（默认 20 条/页）
5. 点击「导出」按钮，选择「当前视图数据」生成 Excel 文件

#### 预期结果

- 表格左侧固定列 = 用户勾选的维度项（从左到右顺序一致），右侧为指标列
- 所有金额类指标（Revenue）显示为 `$X.XX ` ，百分比类（Rate）保留 2 位小数（如 `32.15%`）
- 筛选变更后，表格 + 指标汇总区在 ≤1.5 秒 内完成刷新
- 导出文件命名：`LocalAdPerformance_{APP}_{DateRange}_{ExportTime}.xlsx`，格式与页面完全一致

#### 数据规则

| 字段                 | 来源          | 计算逻辑/格式要求                                                   |
| :----------------- | :---------- | :---------------------------------------------------------- |
| **DAU**            | 用户行为事实表     | COUNT(DISTINCT user\_id) WHERE active\_date = {date}        |
| **DNU**            | 用户行为事实表     | COUNT(DISTINCT user\_id) WHERE first\_active\_date = {date} |
| **Scene**          | 事件表 (40300) | COUNT(event\_id) WHERE event\_id=40300                      |
| **Show**           | 事件表 (40301) | COUNT(event\_id) WHERE event\_id=40301                      |
| **Click**          | 事件表 (40401) | COUNT(event\_id) WHERE event\_id=40401                      |
| **Scene Rate**     | 计算字段        | `Show / Scene * 100%`，保留 2 位小数                              |
| **Show Rate**      | 计算字段        | `Show / Response * 100%`，保留 2 位小数                           |
| **Click Rate**     | 计算字段        | `Click / Show * 100%`，保留 2 位小数                              |
| **Revenue**        | 变现事实表       | SUM(revenue\_usd)，单位：`$万元`，保留 2 位小数                         |
| **ECPM**           | 计算字段        | `Revenue / Show * 1000`，单位：`$`，保留 2 位小数                     |
| **DARPU**          | 计算字段        | `Revenue / DAU`，单位：`$`，保留 4 位小数（小额场景）                       |
| **Request**        | 事件表 (40101) | COUNT(event\_id) WHERE event\_id=40101                      |
| **Response**       | 事件表 (40201) | COUNT(event\_id) WHERE event\_id=40201                      |
| **Fill Failed**    | 事件表 (40202) | COUNT(event\_id) WHERE event\_id=40202                      |
| **Fill Rate**      | 计算字段        | `Response / Request * 100%`，保留 2 位小数                        |
| **Fill Fail Rate** | 计算字段        | `Fill Failed / Request * 100%`，保留 2 位小数                     |
| **ReqPU**          | 计算字段        | `Request / DAU`，保留 2 位小数                                    |
| **AIPU**           | 计算字段        | `Show / DAU`，保留 2 位小数                                       |
| **ClickPU**        | 计算字段        | `Click / DAU`，保留 2 位小数                                      |

> 📌 口径说明：所有比率类指标分母为 0 时显示 `--`，不计算；Revenue 统一按美元结算，前端展示时追加 `$` 前缀。

### 3.2 原型交互说明（P0）

#### 🧩 顶部筛选区（FilterBar）

**布局描述**

- 通栏 Flex 布局，分三组控件：
  1. **时间筛选**：日期范围选择器（默认 T+1 单日），支持快捷选项
  2. **维度勾选器**：树形 Checkbox 分组展示 4 大类 16 个维度项，支持「全选/清空」
  3. **变现专项筛选**：广告平台（多选）、广告类型（多选）、Union Type（下拉）

**交互行为**

- **维度勾选联动**：
  - 勾选维度项（如 Country）后，自动启用其父级依赖（APP+Version），并置灰不可取消
  - 勾选顺序决定表格固定列顺序，支持拖拽调整列序（P1 优化）
- **级联筛选**：
  - 选择 APP 后，Country/Version 选项动态过滤为该 APP 下可用值
  - 选择广告平台后，广告类型选项过滤为该平台支持的类型
- **查询触发**：
  - 筛选条件变更时自动触发查询（防抖 300ms），「查询」按钮仅用于手动重试

**数据状态**

- Loading：筛选器禁用 + 顶部进度条
- Empty：维度选项无数据时显示 `暂无可筛选项，请检查权限或联系管理员`
- Error：接口失败时保留上次有效结果，顶部 Toast 提示 `数据同步延迟，展示为 T+2 数据`

#### 📊 动态表格区（AdPerformanceTable）

**布局描述**

- **固定列区**：用户勾选的维度项，从左到右排列，最小宽度 120px，支持横向滚动时固定
- **指标列区**：20+ 指标列，按「用户规模→流量→收益→效率」逻辑分组，组间加细分隔线
- **操作列**：右侧固定「导出当前行」按钮（权限控制）

**交互行为**

- **列排序**：点击指标列头切换 asc/desc，仅支持单列排序，默认按日期倒序
- **关键字搜索**：顶部搜索框支持订单号/客户名模糊匹配，实时过滤（≤500ms）
- **列显示控制**：
  - 默认展示核心指标（DAU/Show/Click/Revenue/ECPM/DARPU）
  - 次要指标（ReqPU/AIPU/ClickPU 等）默认隐藏，通过「列设置」开关展示
- **导出交互**：
  - 点击导出 → 选择范围（当前页/全部数据） → 生成文件 → 自动下载
  - 导出进度 >10 秒时显示模态进度条，支持后台导出+站内信通知

**数据状态**

- Loading：表格骨架屏（固定列+3 行指标行）
- Empty：插画 + 文案 `暂无匹配数据，请调整筛选条件`
- Error：行内展示 `加载失败`，支持单行重试

#### 🎨 视觉规范（硬性约束落地）

| 元素类型  | 格式规范                              | 示例           |
| :---- | :-------------------------------- | :----------- |
| 金额指标  | `$` 前缀 + 万元单位 + 2 位小数             | `$125.36 `   |
| 百分比指标 | 数值 + `%` + 2 位小数                  | `32.15%`     |
| 日期字段  | YYYY-MM-DD                        | `2026-05-03` |
| 空值处理  | 显示 `--`，不参与排序/计算                  | `--`         |
| 同比标识  | 正增长 `↑`（#52C41A），负增长 `↓`（#FF4D4F） | `↑ 12.3%`    |

## 4. 非功能需求

- **性能**：
  - 首屏加载（默认查询）≤ 1.5 秒（3G 网络）
  - 筛选变更后数据刷新 ≤ 1.5 秒（P95）
  - 导出 10 万行以内数据 ≤ 30 秒，支持异步导出+通知
- **权限**：
  - 基于 RBAC 实现数据行级隔离：用户仅可查看所属项目组/区域的广告数据
  - 敏感字段（如 ad\_id 明细）对非技术角色自动脱敏
  - 导出操作记录审计日志，保留 180 天
- **兼容性**：
  - 浏览器：Chrome 90+ / Edge 90+ / Safari 14+
  - 分辨率：1920×1080（主）、1366×768（适配滚动）
- **可维护性**：
  - 指标计算逻辑配置化，支持后台动态调整公式/口径
  - 维度项扩展无需发版，通过配置中心新增
