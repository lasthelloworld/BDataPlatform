# 元事件管理模块 — 交互 Demo 实现计划

## Context

PRD 要求建设线上事件元数据字典库，替代线下文档，供 CI/CD 和 ETL 订阅。需新建「元事件管理」一级菜单，下属 4 个子页面。本次先生成交互 Demo 界面（mock 数据），供用户确认后再做细节调整。

## 技术约定

* Vue 3 `<script setup>` + Ant Design Vue 4.x + ECharts

* 主题色 #1677ff、圆角 8px、页面边距 24px

* 所有可交互元素加 `data-marker`；页面底部加 `<details>` 埋点清单

* 文件名 kebab-case，组件名 PascalCase

## 新增文件清单

### 1. 路由注册 — `src/router/index.js`

新增 `/meta-event` 父路由 + 4 个 children：

* `organization` → 事件组织管理

* `code-set` → 编码集管理

* `properties` → 事件属性管理

* `events` → 元事件管理

### 2. 侧边栏 — `src/components/Sidebar.vue`

在 `event-monitoring` 和 `system-settings` 之间新增：

```
📁 元事件管理
  ├─ 事件组织管理
  ├─ 编码集管理
  ├─ 事件属性管理
  └─ 元事件管理
```

### 3. 页面组件 — `src/views/MetaEvent/`

#### (1) `Organization.vue` — 事件组织管理

**布局**：左树 + 右表，上下工具栏

* **左侧树**：`a-tree` 展示 `产品组→品类→产品→主题域` 四级层级

  * 右键节点弹出操作菜单（新增子节点/编辑/删除）

  * 选中节点后右侧表格展示该节点下的事件列表

* **右侧表格**：展示当前选中主题域下的事件（event\_id、事件名称、事件类型、埋点平台、状态）

* **新增节点 Modal**：表单含节点类型（下拉：产品组/品类/产品/主题域）、名称、备注

* Mock 数据：3 个产品组，每组下 2-3 个品类，品类下 1-2 个产品，产品下 2-3 个主题域

#### (2) `CodeSet.vue` — 编码集管理

**布局**：编码集列表 + 编码值列表（主从表）

* **左表/上方**：编码集列表（编码集名称、编码数量、描述、操作列）

* **右表/下方**：选中编码集的键值对明细（键、值、业务说明、操作列）

* **新增/编辑编码集 Modal**：名称 + 描述

* **新增/编辑编码值 Modal**：键、值、业务说明

* Mock 数据：5 个编码集，每个含 3-8 个键值对

#### (3) `Properties.vue` — 事件属性管理

**布局**：顶部筛选栏 + 表格 + Modal

* **筛选栏**：属性名搜索 + 数据类型筛选

* **表格**：属性名、显示名、数据类型（string/int/float/bool/list/enum）、值域引用、备注、操作列

* **新增/编辑 Modal**：

  * 属性名、显示名、数据类型（select）

  * 当类型=list 时，值域字段变为 `a-select` 引用编码集

  * 其他类型直接输入值域文本

  * 备注

* Mock 数据：12-15 条事件属性，覆盖各数据类型

#### (4) `Events.vue` — 元事件管理（核心页）

**布局**：顶部筛选栏 + 事件表格 + 事件编辑抽屉

* **筛选栏**：产品组/品类/产品版本/事件类型/事件ID搜索

* **事件表格**：event\_id、事件名称、事件类型（通用/自定义 tag）、埋点平台（多选 tag）、主题域、产品版本、是否应用内事件、状态、操作列

* **事件编辑 Drawer**（宽 720px）：

  * 基本信息区：event\_id、事件名称、事件类型、埋点平台（多选）、主题域（级联选择）、产品版本（通用事件时隐藏）、是否应用内事件、事件描述

  * **事件属性绑定区**：已绑定属性列表（表格，支持移除）+ 添加属性按钮（弹出选择面板，从事件属性库中多选）

  * **版本控制区**：当前版本号、版本状态（草稿/已发布）、版本历史列表、「继承上一版本」按钮、「发布版本」按钮

  * **版本对比**：选两个版本做 diff（新增/删除/修改的属性高亮）

### 4. 目录结构

```
src/views/MetaEvent/
  ├── Organization.vue     # 事件组织管理
  ├── CodeSet.vue          # 编码集管理
  ├── Properties.vue       # 事件属性管理
```

4. 创建 `Properties.vue` — 列表+表单 Modal
5. 创建 `Events.vue` — 表格+Drawer+版本控制+属性绑定
6. 注册路由 `src/router/index.js`
7. 添加侧边栏菜单 `src/components/Sidebar.vue`
